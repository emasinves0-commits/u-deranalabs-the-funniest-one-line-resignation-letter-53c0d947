# The Funniest One-Line Resignation Letter

A one-line joke program for the make.fun bounty. A rate limiter hands in its notice the day before Black Friday by throttling itself to 0 RPM and naming Dave as its successor. `node main.ts` validates the line (one line, 1 to 140 characters) and writes it to `/output/entry.txt`.

> Effective 11/26: I’m rate-limiting myself to 0 RPM. Black Friday’s your problem now. @Dave, you’re up.
